# Final Project
This is a page intended to give the top 25 career leaders for each major stat category (points, rebounds, assits, steals, blocks)  in NBA history, and also provides links to each page from the individual list pages.

# Interactive Features
Here is a list of features across all of the files that the user can interact with:
- Ability to toggle between light and dark theme on home page
- Search bar on home page to see what stats players are top 25 in
- Videos on each page for each stat leader + YMCA audio on home page
- Quiz format for each stat page (user has to "guess" top 25)
- Ability to reveal all players on each page to exit quiz format
- Button to higlight random player on each stat page
- All pages hyperlinked with one another + link to external NBA.com page for stats
